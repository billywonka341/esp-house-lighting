System Documentation
  1. Fully Standalone: The ESP32-S2 is designed to run completely offline without an active internet connection. All manual push buttons toggle their relays instantly.
  2. Clock Preservation: The system clock will synchronize with NTP when connected to WiFi and preserve accuracy. The device is powered by a UPS ensuring uninterrupted schedule tracking.
  3. Dashboard Access: Connect your phone, computer, or tablet to the same Wi-Fi network and navigate to the IP address shown in the header (e.g. http://192.168.1.15).
  4. Static IP Tip: Reserve a static IP address for the MAC address of the ESP32 in your router settings to prevent it from changing.

⚠️ HIGH VOLTAGE WARNING: AC wiring must only go through the relay contact terminals. Connect AC Live through an ELCB breaker to the Relay COM terminal, then from Relay NO (Normally Open) to the Light terminal 1, and Neutral directly from the neutral bar to Light terminal 2. Keep Earth grounded to metal enclosures.

  • Dashboard won't load: Confirm the device is powered and your device is connected to the exact same WiFi network. Check the Router DHCP list for the IP address.
  • Button does not respond: Check wiring. One pin of the push-button must connect to the correct GPIO and the other side must go directly to a GND pin on the ESP32.
  • Relay does not trigger: Verify the relay board VCC is connected to 5V (not 3.3V). Optocoupler isolated coil relays require a stable 5V supply to energize the coils.
  • Schedules not running: Look at the time in the header. If it displays 00:00 or dates from 1970, NTP synchronization has failed or the network connection was lost.
  • Relays clicking at start: The schedule controller starts only after the 3-minute (180s) boot grace period. No automatic schedule triggers will occur during this interval.
